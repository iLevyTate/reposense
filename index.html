      Controls

      • Drag orbit
      • Scroll zoom
      • Right-drag pan
      • 1 2 3 switch mode
      • T play the tour
      • R start / stop recording
      • P save a PNG
      • F focus the search box
      • Space play / pause the timeline
      • 0 reset the view
      • Esc clear selection · stop the tour
      • Shift+click open the file on GitHub

      Reading the structure

      • Ring: how deep a file sits in the tree
      • Terrace: a directory; everything it contains stands on it
      • Height: file size, on a log scale
      • Colour: language
      • Glow: churn, when history is available

      Chronology

      • Bars: commit activity per period; the played span is lit
      • White flare: a file at the moment of its creation
      • Playhead: drag it, or press Space to replay the history
